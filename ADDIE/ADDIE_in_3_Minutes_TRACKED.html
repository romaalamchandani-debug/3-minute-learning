The framework

Five stages. One learning cycle.

ADDIE is a structured way to create learning experiences. Select each stage to preview the question it answers.

Select a stage above.
A
01 • Analyze

Start with the problem.

Identify the audience, performance gap, context and constraints. Training is useful only when you understand what needs to change.

Example: New analysts are making reporting errors. Before building a course, check whether the cause is missing knowledge, unclear process, or lack of practice.
D
02 • Design

Plan the learning experience.

Define measurable objectives, sequence the content, choose activities and decide how learning will be assessed.

Think: “By the end, learners can correctly complete the reporting workflow using the standard checklist.”
D
03 • Develop

Build and test the solution.

Create the slides, eLearning, facilitator guide, job aids, scenarios or assessments defined during Design. Review for accuracy and usability.

Key distinction: Design decides what the experience should be; Develop produces the actual learning assets.
I
04 • Implement

Put learning into practice.

Launch the learning, prepare facilitators and learners, manage access and communication, and make sure the experience works in the real environment.

Example: Publish the module in the LMS, enroll learners, brief the trainer and provide the supporting checklist.
E
05 • Evaluate

Check whether it worked.

Use feedback, assessment results and performance data to judge effectiveness—and feed what you learn back into the next iteration.

Look beyond: “Did learners like it?” Also ask: “Can they perform the task more accurately now?”

3-minute takeaway

ADDIE keeps learning intentional.

It is not simply a checklist. Evaluation can reveal a new need and send you back to Analyze, making ADDIE an iterative cycle.
